The **ai-client-determ** application is one of the components of the **RAGdeterm** solution,
which are presented below:

![Image description](docs/figure/02-soft-arch.png)

The **ai-client-determ** application developed using Spring Boot and Spring AI 
libraries exposes REST service leveraging the **RAGdeterm** mechanism for prompt
enrichment and communicates with an LLM via the OpenAI API. In this
project, **prompt-enricher** is used as a library.

The application description can be found in this document:

[Application architecture and functionality](docs/application-architecture-and-functionality.md)
